# 行程编排原则

## 判断顺序

1. 天数是否够（往返驾驶天数先扣掉）  
2. 核心游玩区秋景/季节窗口  
3. 用户指定返程城市（如青岛）是否占一天  
4. 是否「不赶」→ 日均里程与停留点配比  
5. 最后才补美食、天气  

## 结构模板

- **去程**：约 3 天，日均 600–950km，每段 1–2 个顺路 30–60min 停留  
- **核心**：约 5 天，日均 ≤450km，摄影黄金时段留给主景点  
- **返程**：约 3 天，可绕用户点名城市  

## 文案

- 日期行：`D2 9.26 蚌埠 → 承德 → 赤峰 ~850km · 大明湖 / 棒槌山`  
- 只写**城市**；去掉「山姆」「出发」  
- 顺路点：城市级地标即可，不硬塞远郊  

## 删减（明说删了什么）

- 日均已 >950km 仍塞远郊 → 删  
- 与主景同质的次要公园 → 只留一处  
- 节假日爆满且可绕开的点 → 标「有余力再去」  

## 美食

- 融入对应城市点位：`🍜 绍兴 · 黄酒/茴香豆` + 点评搜索词  
- 不为名店反向扭曲路线；写本地口碑/扫街常见即可  
- 导航与「去吃」都用 **城市名**  

## 天气

- Open-Meteo 或用户数据；查不到就省略  
- 每天一条即可，写温差与穿衣/睡车提醒（如「阿尔山 1~10°C 保暖」）  
- 与点位卡片内天气去重  

## 配图

- 一景一图、不复用  
- 真实景点照优先；搜不到**不配图**  
- 禁止珠宝/地图/动物/明星/海报等无关图

# 纯电充电 · 车中泊 · 保暖

## 充电纪律

1. 单段规划 **≤300km** 就有下一个高速口/县城快充  
2. 电量 **30% 前**进桩，不赌下一站  
3. 高速服务区节假日可能排队 → 备选出口 1–3km 内商场/停车场桩  
4. **承德 → 赤峰 → 阿尔山 → 根河** 山区桩距变大：进山前 **90%+**  
5. App 建议同时装：加电、特来电、星星充电、国网 e 充电  
6. 节点命名：`①湖州/长兴`、`⑤承德/平泉（务必满）`，便于按城搜桩  

## 节点参考节奏（单程约 280–300km 一跳）

绍兴 → 湖州/长兴 → 蚌埠/宿州 → 济南/德州 → 天津/廊坊 → 承德/平泉 → 赤峰 → 通辽 → 乌兰浩特 → 阿尔山 → 海拉尔  

返程按城市反向复制，或按返程走廊（如青岛线）重排。

## 车中泊

- 优先：高速服务区、县城大型停车、景区官方停车  
- 避免：偏僻林道、草场内、河岸斜坡  
- 洗澡：县城洗浴中心 / 酒店钟点房  
- 隐私帘 + 干燥剂；清晨玻璃易结霜  

## 保暖（内蒙/大兴安岭 9 月底–10 月初）

| 条件 | 建议 |
|------|------|
| 夜温 10°C+ | 普通春秋被 |
| 夜温 0–8°C | **0℃ 舒适温标睡袋** + 睡垫隔冷 |
| 夜温 ≤0°C | 0℃ 以下睡袋；可开暖风预热后关 |

- 纯电整夜暖风约 1–3 kW，8 小时约 8–20 度电（热泵更省）  
- 推荐：睡前 22–24°C 预热 → 被窝里改 18°C 或关机  
- 满电再睡，或预留次日 50km+ 缓冲  
- 睡垫/纸板隔底板比多盖一床更管用  

## 车型续航假设

路书按 **500km 级** 纯电写「约每 300km 一充」。实际按用户车续航、是否开暖风、载重微调。
